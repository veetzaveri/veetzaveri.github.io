# Veet Zaveri — GitHub Pages Research Website

This repository is the source for:

https://veetzaveri.github.io/

## Site files

- `index.html` — homepage and selected research
- `research.html` — detailed research projects
- `publications.html` — publications and DOI links
- `experience.html` — research/engineering experience, education, and skills
- `styles.css` — shared site styling
- `Veet_Zaveri_Resume.pdf` — public résumé used by the Resume buttons

## Publish / update

Because the repository is named `veetzaveri.github.io`, push these files directly to the root of the `main` branch.

If GitHub Pages is not already enabled:

1. Open **Settings → Pages**
2. Choose **Deploy from a branch**
3. Select **main**
4. Select **/(root)**

The site should deploy at:

https://veetzaveri.github.io/

## Updating the site later

Edit the HTML files, commit, and push to `main`. GitHub Pages will redeploy automatically.
