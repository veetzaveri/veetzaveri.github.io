# Veet Zaveri — GitHub Pages Research Site

This folder is ready to use as a simple static GitHub Pages website.

## Files
- `index.html` — homepage
- `research.html` — research project details
- `publications.html` — publications and manuscripts
- `experience.html` — research/leadership experience
- `styles.css` — shared styling
- `Veet_Zaveri_Resume.pdf` — **add your actual resume PDF with this exact filename**

## Before publishing

Search all files for the following placeholders and replace them:

- `YOUR_GITHUB_USERNAME`
- `YOUR_LINKEDIN_SLUG`
- `YOUR_EMAIL`
- `YOUR_ICP_FORK_NAME`
- `YOUR_JOB_TITLE`
- `YOUR_ORGANIZATION`
- `Replace with dates`
- publication citation TODOs

You can do this in VS Code with **Ctrl+Shift+F**.

## Publish with GitHub Pages

1. Create a repository named exactly:
   `YOUR_GITHUB_USERNAME.github.io`
2. Put these files in the repository root.
3. Add your resume as `Veet_Zaveri_Resume.pdf`.
4. Commit and push to the `main` branch.
5. In GitHub, open **Settings → Pages** and, if needed, select:
   **Deploy from a branch → main → /(root)**.
6. Your site will be available at:
   `https://YOUR_GITHUB_USERNAME.github.io`
